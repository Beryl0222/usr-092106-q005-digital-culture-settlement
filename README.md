# 新大众文艺分账网关

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件信封（基础字段、聚合类型、事件名称）。
- `contracts/event-catalog.md`：事件目录，逐类说明 payload 约定、敏感分级与领域规则 R1–R6。
- `src/validator.py`：事件信封校验。
- `src/ledger.py`：按结算批次重放分录并验证守恒。
- `src/rules.py`：领域规则校验（封账、复用计酬、分期确认、争议暂存、权利范围）。
- `src/analytics.py`：趋势分析投影，剔除个人轨迹与未公开单价。
- `data/sample.json`：最小样例记录。
- `data/scenario_cross_media.json`：跨媒介联调场景（网文改编短剧、非遗直播，含迟到渠道单差额调整与争议暂存释放）。
- `tests/`：验证样例、场景与领域规则保持一致。

## 领域边界

当前资料围绕跨媒介权利、收入确认和贡献分账整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

- 一笔收入可回溯到消费或渠道单、作品版本、契约标识与逐项扣减原因。
- 预付会员收入先递延，随实际消费分期确认；同一笔支付的确认与退款合计不超过递延。
- 直播回放、短剧剪辑等复用素材的消费不再按次计酬，其收入经渠道单广告分成进入。
- 已封账周期只接受迟到渠道单的差额调整，调整入账到开放批次。
- 合同修订、作者退出、侵权冻结、内容下架只约束列明的权利项，自生效时刻起约束该项下的分账。
- 争议款按争议当事方暂存，无争议贡献者的分账在同一批次正常入账。
- 趋势分析只读投影，不含个人标识与未公开单价。
