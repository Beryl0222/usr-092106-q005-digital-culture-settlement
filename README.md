# 新大众文艺分账网关

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。
场景：非遗直播、按集短剧、连载网文共用同一会员体系，打赏、解锁、订阅、广告分成、
联合会员退款在不同结算周期到达——后端负责把每一笔收入正确归属到消费、作品版本、
合同与贡献者。

## 内容

- `contracts/domain.schema.json`：领域事件契约。信封字段、事件/聚合枚举、复式分录、
  关联链接、归属主体与可见性。历史五事件四聚合保持有效，新增字段全部可选。
- `docs/domain.md`：事件目录、聚合、会计科目表与八条全局不变量。
- `data/sample.json`：最小信封样例（历史）。
- `data/scenario.json`：贯穿全部规则的跨媒介验收样例。
- `src/validator.py`：基础事件信封校验。
- `src/ledger.py`：按批次重放、单事件/整批借贷守恒、封账冻结与迟到单调整校验、
  递延收入随消费确认校验。
- `src/access.py`：地域/期限权利注册表——改编合同选择、合同修订、作者退出、
  侵权冻结、内容下架的最小范围判定。
- `src/projection.py`：只读投影——创作者单笔收入追溯（消费/版本/扣减原因）
  与趋势分析脱敏聚合（无个人轨迹、无未公开单价）。
- `tests/`：信封一致性与八条不变量的验收测试。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正只产生后继记录
（红冲、差额调整），后继事件继续使用既有契约标识。涉及个人、机构或商业敏感信息时，
调用方只读取完成职责所必需的字段：财务可见内部分录，创作者可见自己的收入与扣减原因，
趋势分析只能读取公开聚合。

关键规则（详见 `docs/domain.md`）：

1. 单事件按币种借贷平衡，整批重放试算平衡。
2. 封账后批内分录冻结；迟到渠道单只经 `ADJUSTMENT_POSTED` 差额调整进入新批次。
3. 预付会员收入随实际消费分期确认，退款只退未消费的递延余额。
4. 直播回放、短剧剪辑复用已计酬素材时不重复计酬，仅新增价值可分账。
5. 合同修订、作者退出、侵权冻结、内容下架只约束其显式权利范围。
6. 争议款进入暂扣专户，不拖累无争议贡献者排款。
